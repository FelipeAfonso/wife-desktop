# wife-desktop

Config for **ulthar**, the CachyOS (Arch) desktop that Felipe's wife
games and browses on. The desktop is CachyOS's own Hyprland + Noctalia
preset (`cachyos-hypr-noctalia`), kept as installed and bent toward the way
Felipe's machine ([personal-desktop](https://github.com/FelipeAfonso/personal-desktop),
miskatonic) behaves: same keybinds, same two-monitor workspace layout, same
terminal and shell, plus gaming window rules. The goal is a machine that
runs World of Warcraft without a desktop panel fighting it, looks cozy, and
that Felipe can debug from another room with agents over T3 Code.

The name is from "The Cats of Ulthar": the town where no one may kill a
cat. Hardware is Felipe's old AMD RX 6950 XT and two 4K monitors (Dell on the
left, LG on the right); keyboard is a US layout with the `alt-intl`
variant because she types in Brazilian Portuguese.

Fleet canon: `rlyeh` (server, [personal-server](https://github.com/FelipeAfonso/personal-server)) ·
`miskatonic` (Felipe's desktop, [personal-desktop](https://github.com/FelipeAfonso/personal-desktop)) ·
`ulthar` (this desktop) ·
`yuggoth` (MacBook, [personal-laptop](https://github.com/FelipeAfonso/personal-laptop)).

## What was changed from the CachyOS preset

Each change is a few commented lines in `hypr/config/*.lua` or
`noctalia/config.toml`, so `skel-diff` stays readable.

- **Keybinds like miskatonic.** Super+number goes to workspace 1-4
  (1-2 on the left monitor, 3-4 on the right), Super+Shift+number sends the
  window there. Super+G goes to the gaming workspace, Super+Shift+G sends a
  window there. CachyOS's monitor focus moved to Super+Alt+number. Super
  alone opens the Noctalia launcher (release bind, like the Windows start
  menu); Super+Space still does too. Alt+F4 closes, Super+Q too.
  Super+Escape (`hyprctl kill`) is gone. Super+N opens the browser (the
  preset had it on Super+W). Everything else is the preset's:
  Alt+Tab cycles windows, Super+Tab is the window switcher, Super+V
  clipboard, Print screenshots, Super+L locks, Super+Return a terminal.
- **Monitors pinned.** `variables.lua` names DP-1 (Dell) as `MONITOR1`, the
  primary at 0x0, and DP-3 (LG) as `MONITOR2` at 2560x0; both 4K at 60 Hz,
  scale 1.5. If the mouse crosses the wrong edge, swap the two names there.
- **Keyboard.** `us` + `alt-intl` in `inputs.lua`, matching what the
  installer set for the console.
- **Gaming.** `general.allow_tearing` is on; windows tagged as games
  (`content = game`: Steam apps, gamescope, WoW's Wine classes) get
  `immediate` (tearing) and `idle_inhibit`, on top of the preset's
  fullscreen + `name:gaming` workspace rules. `misc.vrr = 3` is the preset's.
  Battle.net and Lutris float on the primary monitor. The WoW/Battle.net
  class regexes are a best guess until the games are installed.
- **Terminal and shell.** ghostty instead of kitty (`TERMINAL`, `TERM`,
  Noctalia's ghostty template renders `ghostty/themes/noctalia`). Login
  shell is zsh, a few lines with a built-in prompt, not fish.
- **Bar.** Noctalia's Taskbar widget sits in the bar center so open windows
  are clickable, like a Windows taskbar.
- **Wallpaper picker.** Super+W opens miskatonic's rofi image grid (first
  tiles: random, then the previous wallpaper)
  over `~/Imagens/wallpapers` (Felipe's collection, copied over, not in the
  repo). The pick goes to `noctalia msg wallpaper-set`, so Noctalia still
  owns transitions, palette and templates; rofi just borrows the current
  palette for its own colors. The preset's Super+Shift+W (Noctalia's own
  wallpaper panel) is unbound; the panel still opens from the bar.
- **No cachyos-hello.** `export_current` removes its autostart entry.

## Design decisions (short version)

- **Copy, don't symlink.** `export_current` copies repo → `~/.config`;
  `import_current` copies live state back and strips machine junk. Every
  file stays a plain file.
- **Preset first, patches on top.** The CachyOS preset owns the structure.
  Upstream fixes land in `/etc/skel/.config` with each package update and
  never touch the home directory; `skel-diff` shows them, merge by hand,
  commit.
- **The lists are generated, not curated.** pkglists and services.txt are
  dumps refreshed by `import_current`. If a package matters, install it; the
  next import records it.
- **Theming is Noctalia's.** Pick a wallpaper (Super+W) → Noctalia
  derives a Material palette → its templates write `hypr/noctalia.lua`,
  `ghostty/themes/noctalia`, gtk/qt/btop colors. Those generated files are
  committed on purpose, so a fresh export looks right before the first
  wallpaper pick.
- **Agent config is generated, shared with the fleet.** `export_current`
  concatenates `agents/<cli>-global.md` and `agents/models.md` (copies of
  personal-desktop's, sync by hand) with `agents/ulthar-agents.md` into
  each CLI's global prompt file. Edit the repo files and re-export. Skills
  and the unslop hook scripts are vendored the same way. The hooks block in
  `~/.claude/settings.json` is the one by-hand piece:

  ```json
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command",
      "command": "bash ~/.claude/hooks/unslop-reminder.sh", "timeout": 10 }] }],
    "Stop": [{ "hooks": [{ "type": "command",
      "command": "python3 ~/.claude/hooks/unslop-stop-gate.py", "timeout": 15,
      "statusMessage": "Checking unslop compliance" }] }]
  }
  ```
- **One user.** The machine runs a single account (hers, `jacque`).
  Felipe's agent CLIs are authenticated under it so agents can see the
  Steam prefix and browser profile where the bugs are. No secrets repo on
  this box. Tailscale SSH admits `root@ulthar`, not `jacque@`.

## Install (fresh CachyOS)

1. CachyOS installer: hostname `ulthar`, her user, the
   **Hyprland (Noctalia)** desktop, keyboard `us` / `alt-intl`, pt_BR
   locale, btrfs + limine defaults. Boot it; greetd logs into Hyprland.
2. Clone and install packages (paru is in the CachyOS repos):

   ```sh
   git clone https://github.com/FelipeAfonso/wife-desktop ~/code/wife-desktop
   cd ~/code/wife-desktop
   sudo pacman -S --needed - < pkglist-native.txt
   paru -S --needed - < pkglist-aur.txt
   ```

3. Apply configs and units: `./export_current`, then enable whatever in
   `services.txt` is not already on (`sudo systemctl enable <unit>` /
   `systemctl --user enable <unit>`), copy the `/etc` hand-edits, and make
   zsh the login shell:

   ```sh
   sudo cp etc/sysctl.d/99-swappiness.conf /etc/sysctl.d/
   sudo cp etc/modules-load.d/uinput.conf /etc/modules-load.d/
   sudo cp etc/paru.conf /etc/paru.conf
   chsh -s /bin/zsh
   ```

   `uinput` is for OpenLinkHub (Corsair Scimitar side buttons): the packaged
   service runs as its own user and needs the module loaded at boot. Her
   profiles live in `/var/lib/openlinkhub/database/`, restored from the
   Bazzite backup; not tracked here.

4. Agent CLIs as bun globals, not pacman, so the app.t3.codes update button
   can update them without root
   (`systemd/user/t3code.service.d/20-provider-path.conf` puts `~/.bun/bin`
   on the service's PATH):

   ```sh
   bun i -g @anthropic-ai/claude-code @openai/codex opencode-ai
   ```

   Then add the unslop hooks block to `~/.claude/settings.json` by hand
   (snippet above).

5. Monitors: `hyprctl monitors` shows the names; `hypr/config/variables.lua`
   expects DP-1 on the left and DP-3 on the right.
6. Wallpapers: copy a collection into `~/Imagens/wallpapers` (miskatonic's
   is at `~/media/wallpapers`). Super+W picks one.
7. Sign-ins: `sudo tailscale up --ssh`, `gh auth login`, `claude`, `codex`,
   Steam, Battle.net. Device-code flows all work the same way: run, open
   URL, approve. Then `systemctl --user enable --now t3code.service` and
   confirm the machine shows up in app.t3.codes.
8. Log out and in (or `hyprctl reload`) so uwsm picks up the new env.

Known manual gaps: WowUp's addon list; Steam library; the WoW window rule
classes.

## Day-to-day

- Machine changed → `./import_current`, review the diff, commit. Repo
  changed → `./export_current` (reloads Hyprland and Noctalia when run
  inside the session).
- After an update that touches `cachyos-hypr-noctalia`, run `skel-diff` and
  merge what upstream changed.
- Keep Hyprland at the same version as miskatonic. When something breaks
  after an update, a version mismatch between the two boxes is the first
  suspect.

## Validation

After an export: `zsh -ic exit` (shell loads), `hyprctl reload` (no config
errors in `hyprctl configerrors`), `noctalia config validate`. The smoke
test is a login: greetd → Hyprland → Noctalia bar up on both monitors,
Super opens the launcher, Super+2 lands on the left monitor and Super+3 on
the right, WoW goes fullscreen with no bar visible.
