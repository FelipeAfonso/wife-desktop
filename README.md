# wife-desktop

Config for **ulthar**, the CachyOS (Arch) desktop that Felipe's wife
games and browses on. Forked from
[personal-desktop](https://github.com/FelipeAfonso/personal-desktop)
(miskatonic) and trimmed: same Hyprland, same theming pipeline, same
copy-based sync, none of the developer tooling. The goal is a machine that
runs World of Warcraft without a desktop panel fighting it, looks cozy, and
that Felipe can debug from another room with agents over T3 Code.

The name is from "The Cats of Ulthar": the town where no one may kill a
cat. Hardware is Felipe's old AMD RX 6950 XT; keyboard is a US layout with
the intl variant because she types in Brazilian Portuguese.

Fleet canon: `rlyeh` (server, [personal-server](https://github.com/FelipeAfonso/personal-server)) ·
`miskatonic` (Felipe's desktop, [personal-desktop](https://github.com/FelipeAfonso/personal-desktop)) ·
`ulthar` (this desktop) ·
`yuggoth` (MacBook, [personal-laptop](https://github.com/FelipeAfonso/personal-laptop)).

## What is different from miskatonic

- **Gaming window rules.** `steam_app_*` and WoW's Wine classes get
  fullscreen, `immediate` (tearing) and idle inhibit. `misc.vrr = 2` turns
  VRR on for fullscreen windows only. Launchers (Battle.net, Lutris, Steam
  dialogs) float. Fullscreen windows cover waybar on their own; nothing to
  configure.
- **Mouse-first keybinds.** Super alone opens rofi (like the Windows start
  menu), waybar has a start button and clickable workspaces, Alt+Tab
  cycles windows, Alt+F4 closes, arrows instead of hjkl. Workspaces are
  Super+number. The full list is at the bottom of `hypr/hyprland.lua`.
- **Wallpaper is pinned, not rotated.** Login restores the last chosen
  wallpaper (`hypr/scripts/restore-wallpaper.sh`); `SUPER+W` picks a new
  one. Wallpapers live in `~/Pictures/wallpapers`, no external drive.
- **No dev stack.** nvim, tmux, lazygit, opencode, starship, git config,
  the custom XKB layout, secrets, and the AppImage helpers are gone. zsh is
  a few lines with a built-in prompt. Agent CLIs stay (bun globals) because
  T3 Code needs them.
- **Package lists are seeded, not measured.** They were pruned by hand from
  miskatonic's dumps. The AMD GPU packages (`vulkan-radeon`,
  `lib32-vulkan-radeon`, `xf86-video-amdgpu`) are right for the RX 6950 XT;
  `amd-ucode` assumes an AMD CPU too, swap for `intel-ucode` if not. The
  first `./import_current` replaces both lists with reality.

## Design decisions (short version)

- **Copy, don't symlink.** `export_current` copies repo → `~/.config`;
  `import_current` copies live state back and strips machine junk. Every
  file stays a plain file.
- **The lists are generated, not curated.** pkglists and services.txt are
  dumps refreshed by `import_current`. If a package matters, install it; the
  next import records it.
- **Theming is one pipeline.** Pick a wallpaper (`SUPER+W`) → wallust
  renders `wallust/templates/` → hypr/waybar/dunst/rofi/ghostty/zsh pick up
  the palette → `hypr/scripts/apply-theme.sh` reloads everything. The
  generated color files are committed on purpose.
- **Agent config is generated, shared with the fleet.** `export_current`
  concatenates `agents/<cli>-global.md` and `agents/models.md` (copies of
  personal-desktop's, sync by hand) with `agents/ulthar-agents.md` into
  each CLI's global prompt file. Edit the repo files and re-export. Skills
  and the unslop hook scripts are vendored the same way. The hooks block in
  `~/.claude/settings.json` is the one by-hand piece:

  ```json
  "hooks": {
    "UserPromptSubmit": [{ "hooks": [{ "type": "command",
      "command": "bash ~/.claude/hooks/unslop-reminder.sh", "timeout": 10 }] }],
    "Stop": [{ "hooks": [{ "type": "command",
      "command": "python3 ~/.claude/hooks/unslop-stop-gate.py", "timeout": 15,
      "statusMessage": "Checking unslop compliance" }] }]
  }
  ```
- **One user.** The machine runs a single account (hers). Felipe's agent
  CLIs are authenticated under it so agents can see the Steam prefix and
  browser profile where the bugs are. No secrets repo on this box.

## Install (fresh CachyOS)

1. CachyOS installer: hostname `ulthar`, her user, btrfs + limine
   defaults. Boot it.
2. Clone and install packages (paru is in the native list, CachyOS repos
   carry it):

   ```sh
   git clone https://github.com/FelipeAfonso/wife-desktop ~/code/wife-desktop
   cd ~/code/wife-desktop
   sudo pacman -S --needed - < pkglist-native.txt
   paru -S --needed - < pkglist-aur.txt
   ```

3. Apply configs and units: `./export_current`, then enable everything in
   `services.txt` (`sudo systemctl enable <unit>` / `systemctl --user enable
   <unit>`) and copy the `/etc` hand-edits:

   ```sh
   sudo cp etc/sddm.conf /etc/sddm.conf
   sudo cp etc/sysctl.d/99-swappiness.conf /etc/sysctl.d/
   sudo cp etc/paru.conf /etc/paru.conf
   ```

4. Agent CLIs as bun globals, not pacman, so the app.t3.codes update button
   can update them without root
   (`systemd/user/t3code.service.d/20-provider-path.conf` puts `~/.bun/bin`
   on the service's PATH):

   ```sh
   bun i -g @anthropic-ai/claude-code @openai/codex opencode-ai
   ```

   Then add the unslop hooks block to `~/.claude/settings.json` by hand
   (snippet above).

5. Locale: pick `pt_BR` for formats in the installer or set
   `LC_TIME`/`LC_NUMERIC` in `/etc/locale.conf` afterwards; the keyboard is
   already `us` + `intl` in `hypr/hyprland.lua`.
6. Monitor: `hyprland.lua` auto-detects. Pin the real output and refresh
   rate once known (`hyprctl monitors` shows the name).
7. Wallpapers: `mkdir -p ~/Pictures/wallpapers`, drop images in, press
   `SUPER+W`.
8. Sign-ins: `sudo tailscale up`, `gh auth login`, `claude`, `codex`,
   Steam, Battle.net. Device-code flows all work the same way: run, open
   URL, approve. Then `systemctl --user enable --now t3code.service` and
   confirm the machine shows up in app.t3.codes.
9. Reboot. SDDM autologs into Hyprland.

Known manual gaps: the SDDM "silent" theme (`/usr/share/sddm/themes/silent`,
no package owns it); WowUp's addon list; Steam library.

## Day-to-day

- Machine changed → `./import_current`, review the diff, commit. Repo
  changed → `./export_current`.
- Keep Hyprland at the same version as miskatonic. When something breaks
  after an update, a version mismatch between the two boxes is the first
  suspect.

## Validation

Nothing in this repo has been run on real hardware yet (2026-09-08). After
the first export: `zsh -ic exit` (shell loads), `hyprctl reload` (no config
errors), `bash -n` the touched scripts, `waybar` from a terminal to catch
config typos. The smoke test is the reboot: SDDM → Hyprland → waybar/dunst
up, Super opens rofi, `SUPER+W` themes the world, WoW goes fullscreen with
no bar visible.
